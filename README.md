# <img width="64" src="default256.png" alt="Logo" /> Firefox for windows 7 <img width="64" src="xp_flag.png" alt="Logo" />

[Firefox](https://firefox.com/) is a fast, reliable and private web browser from the non-profit [Mozilla organization](https://mozilla.org/).

Firefox 115 is the last version to support Windows 7/8/8.1. This repository includes patches that enable newer versions of Firefox to run on Windows 7/8/8.1.

## Platform Support

Windows 7/8/8.1.

![](app.png)

might also work on Windows XP SP3 and Windows Vista.
